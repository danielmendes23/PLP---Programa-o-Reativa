# Checklist de revisão final com parceiro

- [ ] Ambos entendem a regra de terceira leitura >=30 °C e normalização <28 °C.
- [ ] Projeto inicia com Node 22+, `npm install`, `npm run demo`.
- [ ] `npm run validate` passa na implementação de referência.
- [ ] `npm run offline` executa testes sem pacotes npm externos (Node 22+).
- [ ] Agentes executados em contextos separados, com mesmo modelo e prompt.
- [ ] `runs/trial-*` não recebe solução pronta ou testes externos antes da geração.
- [ ] Intervenções humanas registradas ou zero confirmado explicitamente.
- [ ] Avaliação comum ocorre só depois de ambas as gerações.
- [ ] Todos os números do vídeo saem de arquivos JSON/logs reais.
- [ ] README com passos reproduzíveis, vídeo publicado e GitHub público.
