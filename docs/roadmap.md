# Roadmap enxuto — 7 etapas

| Dia | Fazer | Critério de conclusão |
|---|---|---|
| 1 | Confirmar prompt, requisitos e arquitetura | Regras e limites congelados |
| 2 | Configurar projeto, simulação e testes independentes | Scripts de avaliação preparados |
| 3 | Criar AGENTS.md, regras, lint e validações do harness | Harness testa regras e falhas intencionais |
| 4 | Executar dois agentes isolados com o mesmo prompt | Código e transcrições preservados |
| 5 | Rodar auditoria comum e comparar métricas | Resultados brutos, tabela sem números inventados |
| 6 | Produzir README e gravar demonstração | Vídeo mostra código, testes e evidências |
| 7 | Revisar, publicar GitHub e enviar links | Repositório público e vídeo acessível |

## Divisão entre dois integrantes

- **Pessoa A:** estrutura, harness, configurações, testes de arquitetura e CI.
- **Pessoa B:** testes independentes, protocolo, logs, análise e organização do vídeo.
- **Ambos:** executar/supervisionar as duas condições e revisar conclusões.

O repositório entregue já inclui a implementação de referência, infraestrutura de avaliação,
roteiros e scripts. Os experimentos e publicação exigem execução humana independente.
